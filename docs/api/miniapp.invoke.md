# miniapp.invoke

Вызывает экспортированный метод другого мини-приложения. Если целевое служебное приложение ещё не загружено, оболочка загружает его в скрытый iframe.

- **Обработчик:** `apps/shell-mobile/www/js/api/miniapp/invoke.js`
- **Разрешение:** не нужно (разрешения проверяет вызываемый метод)
- **Статус:** реализован

## Параметры
| Поле | Тип | Описание |
|---|---|---|
| `appId` | string | ID целевого мини-приложения |
| `method` | string | Имя метода, экспонированного через `MappHub.expose` в целевом приложении |
| `params` | object | Аргументы. Функции передаются как колбэки и вызываются обратно из целевого приложения |

## Вызов
```js
const tab = await MappHub.invoke("com.mapphub.browser", "browser.open", {
  url: "https://example.com",
  right: { icon: "★", onTap: () => console.log("tap") },
});
```

Колбэки работают, пока вызывающее приложение остаётся основным. Если оно уступило экран другому приложению, колбэк не сработает.
