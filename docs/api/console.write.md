# console.write

Пишет строку в ленту консоли оболочки с источником, равным названию вызывающего мини-приложения. `MappHub.js` вызывает его автоматически при `console.log/info/warn/error/debug` внутри мини-приложения, поэтому обычно вручную не нужен.

- **Обработчик:** `apps/shell-mobile/www/js/api/console/write.js`
- **Разрешение:** не нужно
- **Статус:** реализован

## Параметры
| Поле | Тип | Описание |
|---|---|---|
| `level` | string | `log`, `info`, `warn`, `error` или `debug`; иное значение считается `log` |
| `text` | string | Текст сообщения, до 10000 символов |

## Вызов
```js
await MappHub.call("console.write", { level: "warn", text: "что-то пошло не так" });
```
