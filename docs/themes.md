# Темы и токены

Тема — это один CSS-блок `:root { … }` с переменными `--mapp-*`. Оболочка отдаёт его
мини-приложениям по `https://mapp.local/theme.css`, поэтому токены видны всему, что
запущено в рантайме.

## Хранение

- Наборы тем лежат в `system_kv` под namespace `themes`: `themes/light`, `themes/dark`, `themes/<id>`.
- Активная тема — `config/active_theme`.
- `light` и `dark` заводские: их нельзя перезаписать через `theme.save`, но можно вернуть к
  исходному виду через `theme.reset`. Исходный текст — константы `LIGHT_CSS` / `DARK_CSS`
  в `MappDatabaseHelper`.
- Чтение доступно без разрешения. Запись требует `system.theme.write`.

## Формат

Правила, которые проверяет `MappThemeCss.canonicalize` на стороне нативной части и
`validateValue` / `buildRootCss` в редакторе:

- Ровно один блок `:root { … }`, без селекторов вокруг.
- Имена переменных — `--[A-Za-z0-9_-]{1,64}`.
- В значениях запрещены `{`, `}`, `<`, `>`, `@`, обратная косая черта и функции `url()`,
  `image()`, `image-set()`, `src()`, `cross-fade()`. Значение с точкой с запятой разрывает
  объявление, поэтому тоже отклоняется.
- Размер блока — не больше 16 КБ.

После сохранения CSS канонизируется: объявления нормализуются (два пробела отступа,
`;` в конце каждой строки). Поэтому сохранённый текст может отличаться от введённого
пробелами, но не значениями.

## Категории токенов

Каталог описан в `miniapps/theme-editor/tokens.js` (`TOKEN_CATALOG`). Он определяет порядок
категорий, подписи, значения по умолчанию и тип контрола.

| Категория | id | Контрол |
|---|---|---|
| Цвета | `colors` | свотч + поле hex |
| Скругления | `radius` | степпер `− / +` с шагом 1px |
| Отступы и размеры | `spacing` | степпер |
| Типографика | `typography` | степпер для размеров, текст для `font-family` |
| Контролы и компоненты | `controls` | степпер |
| Прочее | `misc` | по типу значения |

Раздел «Прочее» появляется сам: туда попадают переменные, которых нет в каталоге. Они не
теряются при сохранении и остаются редактируемыми.

## Алиасы

Исторически токены назывались `--mapp-color-*`, а в новых местах используются короткие
имена `--mapp-bg`, `--mapp-surface`, `--mapp-radius` и т. п. Каталог знает оба варианта:
у записи есть `name` (каноничное имя) и `aliases`. Строка редактора привязывается к тому
имени, которое реально есть в теме (`boundName`), чтобы правка не создала второй,
неработающий токен. Если в теме нет ни одного из имён — строка показывает значение по
умолчанию и записывает его под каноничным именем.

## Редактор тем

`miniapps/theme-editor` — обычное (не системное) мини-приложение с правами
`system.theme.read` и `system.theme.write`.

- Категории свёрнуты в спойлеры; состояние раскрытия хранится в `localStorage`
  (`theme-editor:open-sections`), по умолчанию раскрыты «Цвета».
- Правки сразу применяются к самому редактору, поэтому изменения видно без сохранения.
- Кнопка «Сохранить» недоступна на заводских темах, «Сброс» — на пользовательских.
- «Копия» сохраняет текущий набор под новым id, «Применить» делает тему активной.
- Поиск фильтрует строки по имени токена, подписи и значению.
- Блок «Сырой CSS» — тот же набор токенов в текстовом виде, синхронизируется в обе стороны.
- Точка в заголовке категории означает, что в ней есть значение, отличное от значения по
  умолчанию.
