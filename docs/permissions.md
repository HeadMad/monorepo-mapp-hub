# Модель разрешений

Разрешения нужны только там, где экшен может затронуть то, что выходит за пределы каталога мини-приложения. Экшены, которые работают только внутри собственного каталога приложения, разрешений не требуют.

## Классы экшенов

| Класс | Что значит | Разрешение |
|---|---|---|
| Песочница | Влияет только на каталог и данные самого мини-приложения, либо только рисует интерфейс оболочки | Не требуется |
| Межприложенческий доступ | Читает или меняет другие мини-приложения (их API появятся позже) | Требуется |
| Файловая система | Читает или пишет файлы за пределами каталога приложения | Требуется (API пока не реализован) |
| Нативные функции | Датчики, устройство, сеть-от-имени-пользователя и т. п. | Требуется |

## Классификация реализованных экшенов

| Экшен | Класс | Разрешение в `mappmanifest.json` | Статус |
|---|---|---|---|
| [notifications.alert](api/notifications.alert.md) | Песочница | не нужно | Реализован |
| [shell.checkUpdate](api/shell.checkUpdate.md) | Песочница | не нужно | Реализован |
| [shell.navigate](api/shell.navigate.md) | Песочница (пока) | не нужно | Реализован, см. открытый вопрос |
| [storage.get](api/storage.get.md) | Песочница после исправления | не нужно | Реализован, но не изолирован (см. ниже) |
| [device.info](api/device.info.md) | Нативные функции | `device.info` | Реализован, проверка разрешения не подключена |
| [shell.setTokens](api/shell.setTokens.md) | Затрагивает все приложения | `shell.tokens` (предложено) | Реализован, проверка не подключена |
| [miniapp.install](api/miniapp.install.md) | Межприложенческий доступ | `miniapps.install` (предложено) | Реализован частично |
| [host.setLayout](api/host.setLayout.md) | Служебный iframe | `shell.host` | Реализован |

Открытые вопросы, которые нужно подтвердить:
- `device.info` отнесен к нативным функциям. Это спорно: он отдает только user agent и размер экрана. Можно перевести в песочницу.
- `shell.navigate` сейчас не проверяет цель. Переход на другое мини-приложение нужно считать межприложенческим доступом.
- `storage.get` сейчас читает общий `localStorage` с префиксом `mapp_store_`, без привязки к `appId`. Пока хранилище не изолировано по приложениям, экшен нельзя считать песочницей.

## Как работает запрос разрешений

1. Мини-приложение перечисляет нужные разрешения в `mappmanifest.json` (поле `permissions`).
2. При установке оболочка показывает их в модальном окне с чекбоксами. По умолчанию все включены.
3. Если пользователь снял галочки и нажал «Установить», появляется предупреждение: некоторые функции могут не работать. Кнопки: «Назад» (возврат к чекбоксам) и «Продолжить».
4. Выданные разрешения сохраняются с приложением. Экшен, для которого разрешения нет, должен вернуть `{ ok: false, message }`.

Проверка выданных разрешений в рантайме пока не подключена, см. [TASK-008](../tasks/backlog/TASK-008-permission-enforcement.md).
