# Служебное мини-приложение «Браузер»

`miniapps/browser` — служебное приложение (`"service": true`), которое оболочка загружает по требованию. Оно не отображается в сетке лаунчера. Его API вызывается из других мини-приложений через `MappHub.invoke`. Версия пока однооконная: одновременно открыто не больше одного окна.

Требуемое разрешение: `shell.host` (управление размещением).

## Методы

| Метод | Параметры | Описание |
|---|---|---|
| `browser.open` | `{ appId }` или `{ url }` и настройки ниже | Открывает окно. `appId` открывает установленное мини-приложение, `url` — веб-страницу. Если окно уже открыто, заменяет его содержимое |
| `browser.navigate` | `{ url }` | Переходит по адресу в открытом окне |
| `browser.minimize` | — | Прижимает топбар к низу экрана, основное приложение сжимается |
| `browser.restore` | — | Разворачивает свёрнутое окно |
| `browser.fullscreen` | `{ enabled }` | Полноэкранный режим: топбар скрыт, остаётся полупрозрачная кнопка выхода |
| `browser.close` | — | Закрывает окно |

## browser.open

```js
await MappHub.invoke("com.mapphub.browser", "browser.open", {
  url: "https://example.com",
  title: "Пример",
  left: { preset: "back" },
  right: { icon: "★", onTap: () => {} },
  menuIcon: "⋮",
  menu: [{ icon: "↻", title: "Обновить", onTap: () => {} }],
  fullscreen: { icon: "⤢", size: 36, opacity: 0.5, position: "top-right" },
});
```

- `appId`: id установленного мини-приложения. Страница открывается по адресу `https://miniapp-<appId>.local/index.html`. Пока открыто мини-приложение, его сообщения к шеллу проходят через браузер (`host.relay`): браузер принимает их только от страницы приложения и пересылает в шелл.
- Обычные мини-приложения из лаунчера открываются через браузер. Служебные (`"service": true`) открыть напрямую нельзя.
- `left`: по умолчанию `{ preset: "close" }`. `null` скрывает кнопку.
- `right`: по умолчанию скрыта. Задаётся `{ preset }` или `{ icon, onTap }`.
- Пресеты: `close` (✕), `back` (←), `minimize` (–), `fullscreen` (⤢), `reload` (⟳).
- `icon`: текст или символ, либо URL картинки (`https://…` или `data:image/…`).
- `menu`: если указан массив, показывается кнопка меню (по умолчанию ⋮). Пункты: `{ icon, title, onTap }`.
- `fullscreen`: `icon`, `size` (20–96 px), `opacity` (0–1), `position` (`top-left`, `top-right`, `bottom-left`, `bottom-right`).

## Ограничения

- Кнопка «назад» возвращает к адресу, открытому через API браузера. Переходы внутри страницы она не отслеживает: содержимое в iframe межсайтовое и недоступно из кода.
- Многие сайты запрещают встраивание в iframe (заголовки `X-Frame-Options`, `frame-ancestors`). Такие страницы не откроются.
- Колбэки `onTap` работают, пока вызывающее приложение остаётся основным.
- Работа на физическом устройстве пока не проверена.
