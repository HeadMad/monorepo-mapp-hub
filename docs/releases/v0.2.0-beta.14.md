## MappHub Shell v0.2.0-beta.14

### Fixed
- **Theme changes did not reach the shell or mini-apps.** The `theme.css` generator always returned an empty `:root {}`. On Android, Rhino hands Java strings to JavaScript as wrapper objects (`typeof value === "object"`), and `readKv` checked `typeof value === "string"`, so the active theme was silently dropped. `readKv` now converts the value with `String(...)`. A regression test (`tests/theme/theme-css-java-strings.test.mjs`) reproduces the wrapper case. The fix was also checked against a real Rhino 1.7.15 run: before it the output was empty, after it the `dark` and `light` tokens come through.
- Mini-apps that still hard-coded colours now read the theme. The launcher, market, console, dialogs, browser and sample game link `https://mapp.local/theme.css` and use `--mapp-*` tokens through local `--app-*` aliases. Each keeps its original colour as the `var()` fallback, so the interface still renders if the theme file is missing.
- `ui.getThemeTokens` returns the tokens of the active theme. It used to read a key nothing ever wrote.

### Changed
- The theme editor is styled entirely through `--te-*` aliases onto `--mapp-*` tokens. Editing a colour updates the editor page immediately, with no need to press Apply. Apply saves the theme, activates it, and refreshes the shell and every open mini-app.
- Mini-app versions bumped where their code changed: browser 0.1.0-beta.5, console 0.1.0-beta.5, dialogs 0.1.0-beta.3, launcher 0.1.0-beta.7, market 0.1.0-beta.2, sample-game 0.1.0-beta.3, theme-editor 0.1.0-beta.6.

### Tests
- `npm test`: 79 tests, all green.
- `tests/e2e-theme/e2e-theme.py` (Playwright + Chromium, not part of `npm test`): a host page that mirrors the shell's `theme.css` / `tokens.css` / `themeCss.js` wiring, with the theme editor and launcher in iframes. It checks that Apply changes all three, that a live edit changes the editor at once, and it passes 8/8. With the beta.13 generator and Rhino-style string wrappers it fails on the shell check.

### Not yet verified
