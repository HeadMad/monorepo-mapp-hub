## MappHub Shell v0.2.0-beta.2

### What's new
- **Themes:** theme storage in SQLite (`system_kv`), CSS validation (`MappThemeCss`), asset generation via Rhino on the virtual host `https://mapp.local`.
- **SDK:** `MappHub.js` (renamed from `sdk.js`): event bus `MappHub.events.on/off/once`, theme API `MappHub.theme.*`, generic call `MappHub.call(method, params)`.
- **Theme editor mini-app:** token parser covered by tests (7/7 passing locally).
- **Launcher and sample-game** migrated to `MappHub.js`; the legacy `mapp-bridge.js` is no longer used.
- **Automation:** `CHANGELOG.md` generation and signed APK build in GitHub Actions.

### Known limitations
- Bundled mini-apps are still opened from paths inside the APK, not via `https://miniapp-<id>.local` (TASK-016 is not finished).
- Native code and themes were verified only with JS unit tests and the CI build; they were not tested on a device.
