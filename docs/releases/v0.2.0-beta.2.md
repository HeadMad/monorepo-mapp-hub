## MappHub Shell v0.2.0-beta.2

### Что нового
- **Темы:** хранение тем в SQLite (`system_kv`), валидация CSS (`MappThemeCss`), генерация ассетов через Rhino на виртуальном хосте `https://mapp.local`.
- **SDK:** `MappHub.js` (переименован из `sdk.js`): шина событий `MappHub.events.on/off/once`, API тем `MappHub.theme.*`, общий вызов `MappHub.call(method, params)`.
- **Мини-приложение «Редактор тем»:** парсер токенов покрыт тестами (7/7 пройдено локально).
- **Launcher и sample-game** переведены на `MappHub.js`; старый `mapp-bridge.js` больше не используется.
- **Автоматизация:** генерация `CHANGELOG.md` и сборка подписанного APK в GitHub Actions.

### Известные ограничения
- Встроенные мини-приложения пока открываются по путям внутри APK, а не через `https://miniapp-<id>.local` (TASK-016 не завершён).
- Нативный код и темы проверены только юнит-тестами JS и сборкой CI; на устройстве не проверялись.
