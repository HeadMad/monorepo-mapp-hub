## MappHub Shell v0.2.0-beta.2

### 🚀 Что нового:
- **Шина событий и темы в SQLite:** Добавлено нативное хранение тем в `system_kv`, валидатор CSS `MappThemeCss` и динамический генератор ассетов через Rhino на виртуальном хосте `https://mapp.local`.
- **Клиентский SDK:** Переименован в `MappHub.js`, расширен шиной событий `EventEmitter` и поддержкой `MappHub.theme.*`.
- **Мини-приложение «Редактор тем»:** Полноценный интерфейс для настройки и предпросмотра тем с проверкой переменных (7/7 тестов).
- **Автоматизация релизов:** Настроена генерация `CHANGELOG.md` и сборка signed APK в GitHub Actions.
