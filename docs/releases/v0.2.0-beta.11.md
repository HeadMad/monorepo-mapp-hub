## MappHub Shell v0.2.0-beta.11

### Added
- Dialogs mini-app `com.mapphub.dialogs` (0.1.0-beta.2). Alerts, confirmations, the shell update prompt and the install panel are rendered by it. The shell talks to it over the shared bus.
- Preinstalled mini-apps. Console and dialogs ship inside the shell and are installed on first start, or when the bundled version is newer than the installed one.

### Changed
- `ModalEngine` is replaced by `DialogClient`. The `alert`, `confirm`, `install` and `checkUpdate` APIs keep their signatures.
- Console mini-app 0.1.0-beta.4: the manifest is now `preinstalled`, and the content changed, so the version is bumped.
- `docs/api/bus.md` is marked as implemented and matches the SDK. The `request` method from the earlier draft is not implemented; replies use `reply:<id>` messages.

### Fixed
- System bar insets are applied to the activity content view instead of the WebView, so the WebView and the dialog layer both stay inside the safe area.

### Known limitations
- Not verified on a physical Android device or an emulator. Check dialogs, confirmations, the install panel and the top and bottom insets before relying on this beta.
- Mini-apps that are not preinstalled are not updated by the shell. Update them from the Market.
