## MappHub Shell v0.2.0-beta.8

### Fixed
- The launcher stayed on "Загрузка приложений..." after start. Its script had a syntax error in the color helper (`miniapps/launcher/index.html`), so the app list was never loaded. Launcher version 0.1.0-beta.5.

### Added
- Test `tests/miniapps/inline-scripts.test.mjs` parses the inline scripts of every mini-app, so a syntax error like this fails `npm test`.

### Known limitations
- Not verified on a physical Android device.
