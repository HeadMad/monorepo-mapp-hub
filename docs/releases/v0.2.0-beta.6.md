## MappHub Shell v0.2.0-beta.6

### Added
- Shared event bus `MappHub.bus`: `publish(type, data, { to })`, `subscribe(filter, fn, { replay })` (returns an unsubscribe function). Filters match `type` (exact or prefix ending with `*`) and `app`. Replay returns the last 500 buffered messages. Payloads are limited to 10 KB. See `docs/api/bus.md`.
- Bus APIs `bus.publish`, `bus.subscribe`, `bus.unsubscribe` (subscription requires a direct iframe; it is not available through `host.relay`).
- Console as a service mini-app `com.mapphub.console` (`service: true`, hidden from the launcher). It subscribes to `console.*` on the bus and offers copy and clear buttons.

### Changed
- The shell publishes its own `console.*` messages, uncaught errors and unhandled rejections on the bus with `app: "shell"`. Mini-app `MappHub.js` publishes `console.*` on the bus instead of calling the `console.write` RPC.
- `console.setVisible` and `console.getState` now show and hide the console service mini-app (dock height 260 px). `console.write` publishes to the bus.

### Removed
- The built-in debug console (`debugConsole.js`, its markup and CSS). Its functionality is provided by the console mini-app.

### Known limitations
- Not verified on a physical Android device. The bus-to-console path (iframe, runtime, console service) is covered only by unit tests of the bus module and a syntax check; an end-to-end run in the browser has not been done.
- Bus subscriptions from mini-apps opened inside the browser window (via `host.relay`) are rejected; subscribing from those mini-apps is not supported yet.
