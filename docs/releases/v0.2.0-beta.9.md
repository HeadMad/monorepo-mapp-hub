## MappHub Shell v0.2.0-beta.9

### Fixed
- Safe area support: added `viewport-fit=cover` and CSS `env(safe-area-inset-*)` padding for the shell container, browser app bar/iframe, and launcher. The top status bar and bottom gesture bar/home indicator are no longer overlapped by app content (e.g. browser close cross button is now fully clickable).
- Console service dock and overlay behavior: fixed console sizing and layout handling so it doesn't overlap or distort app views when toggled.

### Updated
- Browser mini-app v0.1.0-beta.3, Console service mini-app v0.1.0-beta.2.

### Known limitations
- Not verified on a physical Android device.
