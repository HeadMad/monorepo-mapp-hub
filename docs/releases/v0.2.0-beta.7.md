## MappHub Shell v0.2.0-beta.7

### Added
- Market mini-app `com.mapphub.market`: installs and updates packages from the catalog published on GitHub Pages (`https://headmad.github.io/monorepo-mapp-hub/index.json`).
- Browser relay forwards bus messages to mini-apps hosted inside the browser window.

### Changed
- The launcher toggles the console service by publishing `shell.console.toggle` on the bus instead of calling the console RPC.
- `bus.publish`, `bus.subscribe` and `bus.unsubscribe` are wired into `MappHostBridge`; themeChanged and bus messages share one delivery path (`deliverToApp`).

### Removed
- Legacy `console.*` RPC API (`console.setVisible`, `console.getState`, `console.write`) and its docs.

### Security
- `miniapp.install` over RPC and relay ignores the `silent` flag, so the permission dialog cannot be skipped.

### Known limitations
- Not verified on a physical Android device.
- Bus subscriptions from mini-apps hosted in the browser window are delivered through the relay; this path has been checked only with unit tests.
