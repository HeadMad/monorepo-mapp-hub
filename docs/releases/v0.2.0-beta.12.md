## MappHub Shell v0.2.0-beta.12

### Added
- Token catalogue in the theme editor. Variables are grouped into Цвета, Скругления, Отступы и размеры, Типографика and Контролы и компоненты, each with a purpose-built control; anything outside the catalogue lands in a Прочее section instead of being dropped.
- `docs/themes.md`: how a theme is stored, the `:root` constraints, the token catalogue and the alias rules.

### Changed
- Theme editor UI: categories collapse into spoilers with the open state kept in `localStorage`, edits apply live, and a dot marks a category holding a non-default value. The search field filters rows by name, label and value.
- Theme editor binds each row to the variable name the theme actually uses. Themes still carry `--mapp-color-*`, so the `--mapp-bg` row edits `--mapp-color-bg` rather than adding a second, dead token.
- Theme editor mini-app `com.mapphub.themeeditor` 0.1.0-beta.5.
- `AGENT_CONTEXT.md` and `docs/README.md` describe theme storage and link to the new document.

### Fixed
- Theme editor stepper threw a syntax error on load: `base ?? parseFloat(...) || 0` mixed `??` with `||`, which is not valid without parentheses, so the page went blank before it rendered.
- `docs/api/README.md` no longer lists the unimplemented `MappHub.bus.request`.

### Tests
- New `tests/miniapps/inline-scripts.test.mjs`: parses every inline `<script>` and every `<script type="module">` of every mini-app, so a mini-app cannot ship with a script that fails before rendering.
- `tests/theme-editor/tokens.test.mjs` covers the catalogue, alias binding, the Прочее fallback and value validation.

### Known limitations
- Not verified on a physical Android device or an emulator. Check the theme editor on a real screen: spoilers, the live preview and the colour picker.
- Mini-apps that are not preinstalled are not updated by the shell. Update them from the Market.
