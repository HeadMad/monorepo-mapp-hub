## MappHub Shell v0.2.0-beta.5

### Added
- Debug console at the bottom of the shell. Hidden by default and no longer remembered between launches. Shown from the launcher settings menu ("Show console" / "Hide console") or with `console.setVisible`. The collapsed strip shows the message count; tap to expand, tap outside to collapse. Copy and clear buttons; select messages to copy only them.
- Mini-app `MappHub.js` forwards `console.*` calls, uncaught errors and unhandled rejections to the shell console, tagged with the mini-app name.
- `console.setVisible`, `console.getState`, `console.write` APIs.
- `miniapp.invoke`: call exposed methods of another mini-app (`MappHub.invoke`, `MappHub.expose`). Functions in parameters are passed as callbacks.
- `miniapp.list` documented. Service mini-apps (`service: true`) are hidden from the launcher grid.
- `host.setLayout` (permission `shell.host`): hide, overlay or dock the service frame.
- Browser mini-app (`com.mapphub.browser`, service): single-window browser with a top bar (left/right buttons, menu), minimize to a bottom dock, fullscreen mode with a floating exit button. API: `browser.open`, `browser.navigate`, `browser.close`, `browser.minimize`, `browser.restore`, `browser.fullscreen`. Only `http` and `https` URLs are opened.

### Changed
- Launcher has a settings button with a menu.
- Launcher `0.1.0-beta.3`.

### Fixed
- The shell layout now includes the service host and debug console containers that the runtime expects at startup.

### Known limitations
- Regular mini-apps opened from the launcher now open inside the browser window (`browser.open` with `appId`). Their messages to the shell are relayed through the browser (`host.relay`).
- Not verified on a physical Android device yet. The service host, `MappHostBridge` frame routing and iframe navigation of the browser mini-app are covered by local jsdom checks only.
