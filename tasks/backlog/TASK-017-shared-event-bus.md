# TASK-017: Общий канал событий (bus) для мини-приложений

## Status: Backlog
## Priority: High
## Source: docs/api/bus.md

### Description
Общее пространство сообщений, через которое мини-приложения и оболочка публикуют события, а подписчики получают нужные им.

- Модель сообщения: `{ type, data, app, id }`. `app` проставляет оболочка по источнику фрейма, `id` генерирует оболочка (короткий хэш).
- Типы: широковещательные (`weather.updated`), адресные (`to:<appId>/<действие>`), ответы (`reply:<id>`).
- Подписки по `type` (точный или префикс `*`) и `app`, без фильтра — все сообщения. `subscribe` возвращает отписку.
- SDK: `MappHub.bus.publish`, `MappHub.bus.subscribe`, `MappHub.bus.request` (publish + ожидание `reply:<id>` с таймаутом).
- Оболочка хранит подписки по фрейму и фильтрует сообщения до доставки.
- Сообщения оболочки: `app = "shell"`.
